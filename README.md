# Bài thực hành phối màu đơn tông

## Phiên bản chính
Bộ màu xanh đơn tông theo yêu cầu:
- Bậc 1: #00ADEE
- Bậc 2: #00B2EF
- Bậc 4: #00BFF2
- Bậc 7: #8DD7F7
- Bậc 9: #C6E9FA
- Chữ: #000000 (các vùng nền đậm dùng chữ trắng để đảm bảo tương phản)

Mở `Pra/index.html` để xem website.

## Phiên bản màu khác
Thư mục `Pra_Alternate` sử dụng một bảng màu xanh ngọc đơn tông khác để đáp ứng bước 8.
